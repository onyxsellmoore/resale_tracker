Role Permission Matrix

Reference this table when applying @RolesAllowed annotations and guarding frontend routes. Admin always has full access.

Endpoint / Action ADMIN BUYER SELLER ACCOUNTANT
POST /api/items — Add inventory ✓ ✓ – –
GET /api/items — View inventory ✓ ✓ ✓ ✓

POST /api/sales — Record a sale ✓ – ✓ –

Engineering Rules

🧪
TDD — failing test first, always Write the test, watch it fail, implement, watch it pass. Every new class, component, and endpoint gets a test written before code exists.
🔐
No unguarded endpoint Every resource method carries a @RolesAllowed annotation. Requests without a valid JWT return 401. Wrong role returns 403. No exceptions.
🏢
orgId always comes from the JWT — never from the client Extract orgId from the verified JWT in every resource. A request body that includes businessId or orgId must be ignored for this field.
💰
BigDecimal for all money — no exceptions Decimal128 in MongoDB, BigDecimal in Java, string-parsed in the frontend. Never float, never double, never integer.
✅
Full suite green before declaring any prompt complete Run ./mvnw test and npm test -- --run before finishing. Every pre-existing test must stay green. Fix any regression before moving on.
